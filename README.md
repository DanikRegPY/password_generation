# Password Generator / Passwort-Generator

## 🇬🇧 English

A lightweight and cryptographically secure command-line password generator built with Python's standard library.

### Features
* **Cryptographically secure:** Uses Python's `secrets` module instead of `random` for high security.
* **Custom length:** Allows users to specify any password length (minimum 4 characters).
* **Flexible character sets:** Option to include or exclude numbers and special punctuation symbols.
* **Input validation:** Ensures correct user responses (`y/n`) and valid integer lengths.

### How to Run
1. Make sure you have Python 3 installed.
2. Run the script in your terminal:
   ```bash
   python password_gen.py
   ```


## 🇩🇪 Deutsch

Ein leichter und kryptografisch sicherer Passwort-Generator für die Konsole, entwickelt mit der Python-Standardbibliothek.

### Funktionen
* **Kryptografisch sicher:** Verwendet das `secrets`-Modul von Python anstelle von `random` für maximale Sicherheit.
* **Benutzerdefinierte Länge:** Frei wählbare Passwortlänge (mindestens 4 Zeichen).
* **Flexible Zeichensätze:** Option zum Ein- oder Ausschließen von Zahlen und Sonderzeichen.
* **Eingabevalidierung:** Überprüft Benutzereingaben (`y/n` und Zahlenwerte) auf Korrektheit.

### Ausführung
1. Stellen Sie sicher, dass Python 3 installiert ist.
2. Starten Sie das Skript im Terminal:
   ```bash
   python password_gen.py
   ```
